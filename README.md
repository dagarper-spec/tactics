# Tactics

RPG táctico HD-2D (three.js, scripts clásicos, sin módulos). Fase 1: una batalla pulida.

Estado: **Hito 6 (parcial)** (batalla completa jugable: turnos, altura y orientación, escudos y Rotura, Potenciar, habilidades de las 4 clases, IA enemiga y pantalla final). Abre `index.html` o activa GitHub Pages (rama `main`, carpeta root).

Controles: tocar/clic = seleccionar unidad o mover a casilla azul · arrastrar = mover cámara · pellizco/rueda = zoom · Q/E o botones = girar 90°.
